# Пояс 4X

Космическая 4X-стратегия на русском (астероиды, корабли с настраиваемыми модулями, корпорации, население Земли, терраформирование, налёты).

## Запуск
Нужен Node.js 20+.

```
npm install
npm run dev      # игра в браузере: http://localhost:5173
npm test         # тесты симуляции без браузера
npm run build    # сборка в dist/
```

## Структура
- `index.html`, `src/style.css` — разметка и стили
- `src/01-data.ts` данные и новая игра · `02-crew.ts` экипаж · `03-build.ts` постройки и наука · `04-engine.ts` ход времени, полёты, приказы
- `05-battle.ts` налёты и бои · `06-corps.ts` корпорации · `07-population.ts` население
- `10-civil.ts` гражданская экономика корпораций: заводы, шахты, рынок, верфь
- `08-map-ui.ts` карта и панели · `09-orders-ui.ts` приказы, конструктор, главный цикл
- `tests/sim.mjs` — тесты симуляции (модули грузятся прямо в Node)

Модули — обычные ES-модули (`import`/`export`), точка входа `src/main.ts`. Единственное изменяемое общее состояние `state` меняется через `setState()`. Чтобы не было циклов при загрузке, межмодульные вызовы в UI идут через `src/00-hooks.ts`. Типы пока отключены (`// @ts-nocheck` в каждом файле): следующий шаг — убирать их по одному модулю и описывать типы корабля, станции и состояния игры.

## Отдельное приложение (Windows .exe)
`npm run dist:win` — собирает игру и кладёт папку `release/win-unpacked` с `Poyas4X.exe` (Electron). Для разработки: `npm run app`.

## Данные игры (правятся без пересборки)
Цены, материалы, характеристики модулей, технологии, товары, законы, параметры боя и регионов лежат в текстовых файлах `public/data/*.json`. В Windows-сборке — папка `data` рядом с `Poyas4X.exe`: открыть блокнотом, поменять число, перезапустить игру. В начале каждого файла — `_readme` с расшифровкой полей. Ошибка в файле (лишняя запятая, кавычка) не ломает игру: берутся встроенные значения, в журнале пишется, в каком файле ошибка.

## Редактор (вкладка «Редактор»)
- **Данные** — таблицы файлов `data/*.json`: добавить запись (пустую или копию существующей), скопировать, удалить, поменять любое поле, добавить поле из уже известных. «Сохранить» пишет файл (в сборке — в папку `data` рядом с exe), «Сохранить и перезапустить» сразу применяет.
- Новые здания работают через поля: `sci` — очки науки в сутки ({phys, eng, bio}), `taxPct` — % к налогам на космос, `beff` — модификаторы за уровень (`mine`, `prod`, `cargo`, `thrust`, `fare`, `fspeed`, `rpcost`, `infra`, `fail`, `repair`, `train`, `death`, `birth`, `sci`, `build`…), `tech` — нужная технология, `cost` — материалы, `sb` — строительные баллы. Новые модули кораблей — из тех же полей, что у существующих; их технология создаётся сама (`m_<id>`).
- **Правила ИИ** (`data/ai.json`) — «если все условия → действие». Корпорации (раз в месяц, первое подходящее правило; можно заменить встроенный ИИ на этот месяц): условия — год, деньги, заводы, шахты, лаборатории, корабли, станции, долг, обеспеченность Земли товаром, цены товаров и руды…; действия — строить заводы товара, шахту, лабораторию, верфь, бюро, корабль-шахтёр, танкер, сменить стратегию, ничего не делать. Корабли (каждый ход): топливо, трюм, износ, расстояние до Земли, чей корабль, роль → вернуться на базу / на Землю. Правки действуют сразу.
