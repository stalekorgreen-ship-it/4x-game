# Пояс 4X

Космическая 4X-стратегия на русском (астероиды, корабли с настраиваемыми модулями, корпорации, население Земли, терраформирование, налёты).

## Запуск
Нужен Node.js 20+.

```
npm install
npm run dev      # игра в браузере: http://localhost:5173
npm test         # тесты симуляции без браузера
npm run build    # сборка в dist/
```

## Структура
- `index.html`, `src/style.css` — разметка и стили
- `src/01-data.ts` данные и новая игра · `02-crew.ts` экипаж · `03-build.ts` постройки и наука · `04-engine.ts` ход времени, полёты, приказы
- `05-battle.ts` налёты и бои · `06-corps.ts` корпорации · `07-population.ts` население
- `08-map-ui.ts` карта и панели · `09-orders-ui.ts` приказы, конструктор, главный цикл
- `tests/sim.mjs` — тесты симуляции (модули грузятся прямо в Node)

Модули — обычные ES-модули (`import`/`export`), точка входа `src/main.ts`. Единственное изменяемое общее состояние `state` меняется через `setState()`. Чтобы не было циклов при загрузке, межмодульные вызовы в UI идут через `src/00-hooks.ts`. Типы пока отключены (`// @ts-nocheck` в каждом файле): следующий шаг — убирать их по одному модулю и описывать типы корабля, станции и состояния игры.
