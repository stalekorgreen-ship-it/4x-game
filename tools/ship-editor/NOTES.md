# Редактор корпусов кораблей — заметки для продолжения

Файл: `tools/ship-editor/index.html` — один HTML без зависимостей, открывается в браузере.
Опубликован как артефакт «Пояс 4X — редактор корпуса» (claude.ai/artifact/HW7wZf1Qn3vEVDNgp9McGF).
Данные модулей и формулы — из Google-таблицы «Пояс», вкладка «Корабли (система)».

## Что умеет
- Корпус из двух силуэтов (сверху / сбоку), углы прилипают к 0/30/45/60/75/90°, ступени 90° — две точки на одном x.
- Сечения: шестигранник, восьмигранник, ромб, короб, круглое. Длина 5–600 м.
- Ярусы надстроек, вырезы (несколько; шире корпуса = срез; броня торцов среза), лобовая плита.
- Броня: основа слоями по 2 см (верх/борт/низ) + накладки в метрах (0,1–200 м), концы скошены 30°.
- Модули (Гатлинг, рельсотроны, осевые рельсотроны, радар, СУО, РЭБ, капсулы), радиаторы 500 K / 1000 K
  с размерами, химические двигатели (1 МН/т, Isp 350 с) в корме или гондолами, декор (шпиль, башня,
  батарея, ребро, антенна, купол), плотность деталей.
- Все модули привязываются к геометрии рейкастом (`snapV/snapH/snapX` по треугольникам `HT` корпуса).
- Несколько тел: доп. корпуса и диски, позиция/поворот (крен, наклон, курс), зеркало, наклонный пилон к основному.
  Модули можно ставить на любое тело (у монтажа поле `bd` = индекс тела, координаты мировые).
- Асимметрия: кривая `topL` (левый борт), применяется пост-трансформом `asymTf`.
- Точки силуэта прямо на 3D-модели (`H3`, перетаскивание решает 2×2 систему по экранным осям).
- Расчёты: масса (итерация как в таблице), объём по внутреннему корпусу, площадь, броня по граням,
  центр масс, ось тяги и смещение, тепло и радиаторы, заполнение объёма зонами.
- Проекты: localStorage (`poyas_ships`) + экспорт/импорт JSON.

## Устройство кода (index.html)
- `S` — текущий корабль: `L, top, up, dn, topL?, asym?, tiers, cuts, ap, nose, ab, mounts, mods, extra[]`.
- Доп. тела: `S.extra[i]` с теми же полями + `kind ('hull'|'disc'), pos, rot[крен,наклон,курс], mir, py, sec, n`.
- Редактирование тела: `enterA()/leaveA()` подменяют поля `S` на поля тела (`KEYS`); `all()` сначала `leaveA()`.
- `build()`: станции → лофт → стенки вырезов → торцы → ярусы → `asymTf` → `buildTris` → `buildExtras`
  → броня/статистика/`calc` → швы/окна/детали → `asymTf` → `buildTris` → двигатели → зоны → монтажи → `COM()`.
- `render()` — свой painter's-рендер в SVG, центр по bbox, масштаб по ограничивающей сфере.
- Грани корпуса помечены `hull:1`, у доп. тел `ext:1`; внутренние блоки рентгена — `z:1`.

## Черновые значения (не из таблицы)
- Объём на тонну: топливо 1 м³/т, реактор 2, погреб 1,2, ангар 25, оружие 3–4, ядро 15, экипаж 25 м³/чел.
- Длины стволов рельсотронов: 10 см — 7 м, 15 см — 10 м, 20 см — 13 м, 30 см — 20 м; внутренняя часть ×2.
- Лазер: перезарядка 60 с (945 МВт).

## Что ещё не сделано / известные упрощения
1. Отсеки (топливо, реактор, экипаж, ангар) живут только в основном корпусе — нужно размещать их в любом теле.
2. Момент инерции и поворотливость (сейчас только смещение ЦМ от оси тяги).
3. Накладки брони на доп. телах не добавляют массу (только базовая броня).
4. Объём/площадь асимметричного корпуса считаются как симметричного.
5. Декор на бортах — упрощённый блок.
6. Плавные стыки между телами.
7. Библиотека декора маленькая (для «готики» в духе Warhammer нужно больше: фигурный нос, ряды батарей по борту).
8. Перенести черновые значения в таблицу «Пояс» после согласования.
