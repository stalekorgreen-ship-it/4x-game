# Надёжность боя: физика, топливо, оружие, ремонт, память

## Топливо и возвращение (`tools/fuel-conv.cjs`)

Результаты: `fuel-convergence.txt`, машиночитаемо — `fuel-convergence.json`.

**Новое: запас топлива маневровых на возвращение — свой у каждого корабля.**
- Формула: `rotF = flips × 2·Fr·(π/slew)/α / vₑ(маневровых)`. Fr — тяга маневровых корабля, α — его угловое ускорение (зависит от массы и длины), slew — экономный разворот.
- Запас вычитается из топлива до расчёта Δv главных двигателей (`budget`, `spendAt`, `resvMin`).
- У фрегата это 3,6 т, у броненосца — 38,3 т. Раньше маневровые не учитывались, и тяжёлые корабли тратили на развороты до трети резерва.

|---|---|---|---|---|

**Не выполнено:**
- Пролёт базы на дальнем перелёте при шаге 0,125 остаётся.
- На дальнем перелёте у базы по-прежнему 6–10 % топлива. Резерв поверх Δv — общая константа (`RET.extra` 0,3 км/с + 15 %), а не своя у каждого корабля.

**Найдено и не исправлено.** Расход маневровых у кораблей вне режима «на базу» зависит от шага физики: в счётчике `rcs` сценария «возврат невозможен» за 8000 с вышло 119 / 232 / 394 / 555 т при шагах 0,5 → 0,0625. Счётчик общий для всего боя, и почти весь этот расход — у стоящего без двигателей корабля-цели. Гистерезис курса для всех кораблей (`move.thy=1`) в двух проверочных сценариях ничего не изменил, а в прежнем прогоне меняли поведение в бою (K14) — поэтому выключен (`thy=0`). Нужен отдельный разбор контроллера курса.

## Этап 2: навигация, развороты, шаг физики

### Пролёт базы на дальнем перелёте — первопричина
- При торможении обратной тягой нос держался на базу. У ошибки скорости была боковая часть: корабль подходит под углом, на 3000 км поперечная скорость около 0,17 км/с. Из-за неё направление нужного импульса отклонялось от оси на ~26°.
- Контроллер включает главный двигатель, только если импульс почти вдоль оси (|df/dl| ≥ 0,97). Двигатель не работал, гасили только маневровые (12 % тяги), и корабль проскакивал базу.
- **Исправление:** при торможении нос строго против нужного импульса — вся поправка, включая боковую, идёт главным двигателем на обратной тяге.
- **Второе:** зона, в которой корабль не поправляет скорость, у базы сужается вместе с нужной скоростью (раньше 0,1 км/с у быстрого перелёта не давало погасить последние 0,05–0,1 км/с).
- Профиль торможения уже учитывал массу и тягу (через ускорение корабля), доступную долю тяги (35 % назад) и время разворота: v·T + v²/2a ≤ d.

**Дальний перелёт, шаги 0,5 / 0,25 / 0,125 / 0,0625:**

| | Было | Стало |
|---|---|---|
| Ближе всего к базе, км | 2,4 / 2,4 / 11,4 / 2,3 | 5,4 / 5,6 / 5,4 / 5,6 |
| Скорость там, км/с | 0,04 / 0,04 / 0,19 / 0,04 | 0,023–0,026 |

- Пролётов больше нет.
- Окончательная остановка в зоне 5 км за 7000 с не завершается: конечный подход идёт по профилю d/300 с, это медленно.

### Запас топлива маневровых
- Считается для каждого корабля: rotF = 3 разворота × 2·Fr·(π/60 с)/α / vₑ, где Fr — тяга его маневровых, α — угловое ускорение от массы и длины.
- Фрегат — 3,6 т, броненосец — 38,3 т.

### Зависимость расхода маневровых от шага — первопричина
- Курс держится зоной ±2°. Без гистерезиса курс стоял на краю зоны и на каждом шаге то включал, то гасил вращение. Каждый такой рывок стоит топлива, и при мелком шаге их больше.
- Прошлый вывод «гистерезис не помог» был ошибкой испытания: стенд подставлял файл настроек репозитория, а не правленый, параметр не применялся.

**Синтетический сценарий** (стоящий корабль следит за медленно уходящей целью), расход маневровых за 7000 с, шаги 0,5 → 0,0625:

| | Расход, т |
|---|---|
| Без гистерезиса | 119 / 232 / 394 / 555 |
| С гистерезисом (доворачивает до 0,3°, начинает с 2°) | 29,3 → 31,1 |

**Реальный бой**, 8 на 8, 6 seed, 1200 с, `combat-step-fuel.txt`:

| | Маневровые, т |
|---|---|
| С гистерезисом | 819 / 903 / 965 / 990 |
| Без гистерезиса | 1055 / 1131 / 1189 / 1120 |

- Гистерезис снижает расход маневровых на 15–22 %.
- Разброс по шагу в бою остаётся 10–20 %. Сам бой при другом шаге идёт иначе: попадания 29 / 49 / 44 / 50 — это хаос боя, а не ошибка интегрирования.
- Шаг 0,5 с грубее остальных (меньше попаданий).
- Главные двигатели: 18–21 км/с суммарного Δv во всех вариантах.
- Ещё одна правка, постоянная времени доворота в секундах вместо «за шаг», на эти числа не повлияла. Она оставлена как корректная, но доказанного эффекта не дала.

## Ракеты (`tools/missile-test.cjs`, результаты — `missile-tests.jsonl`)

**Найдено и исправлено:**
1. **Управляемая ракета за пределами дальности своей головки не включала двигатель** и летела со скоростью носителя, пока не кончалось время. Добавлено командное наведение по данным сопровождения флота (`MIS.mc`). По цели без ПВО попаданий стало 11 из 12 (было 4 из 12, остальные самоликвидировались). По уклоняющейся цели — 3 из 4 (было 0).
2. **Неуправляемая ракета не наследовала скорость носителя**: скорость задавалась заново на каждом шаге. Теперь стартовый импульс складывается со скоростью носителя, дальше — только инерция (`MIS.inh`). В испытании скорость 9,7 против 10,7 км/с у неподвижного носителя.
3. **ПВО сбивала ракеты мгновенно на дальности до 120 км**, хотя пули летят 2 км/с и гаснут через 21 км. Теперь стрельба — только если точка встречи в досягаемости пуль, а попадание засчитывается через время полёта (`pdQ`, `MIS.pdPhys`).
   - Сбито: против управляемых 1 из 12 (было 8 из 8); массовый залп 10 × 4 — 28 сбито, 55 попаданий (было 102 из 102 сбито).
   - **Это заметная смена баланса ракеты / ПВО**, но она следует из физики.
4. Слежение ракеты по высоте (`p.z`) было закомментировано кодом после `//` — исправлено.
5. Суббоеприпасы помечены (`dart`). Раньше в 3D любая обычная ракета рисовалась как суббоеприпас: у них одинаковый `sub===0`.
6. Неуправляемая ракета больше не рисуется с факелом: в полёте тяги у неё нет.

**Испытано:**

| Управляемая | ✓ (вкл. уклоняющуюся цель) | ✓ | ✓ | ✓ | ✓ | ✓ |
