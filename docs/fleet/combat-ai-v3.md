## Где принимаются решения

- **Корабль сам выбирает:** манёвр, ориентацию, уклонение, стрельбу каждого орудия (по своим секторам), момент отхода, ремонт.
- **Флот назначает:** роль, цель (`task.tg`), место в линии (`slot`), кого прикрывать ПВО. Это не траектории: роль и место — штрафы в оценке плана корабля (`RC`, вес `PLN.wrole`), а на цель корабль выходит сам. Это требование «строй — тактическая цель, а не рельсы» система уже выполняла, проверено.
- **Обратная связь:** доклады корабля («не может атаковать цель», «устойчивая угроза», «критические повреждения») снижают ценность цели и запрещают её на время либо переводят корабль в «поддержку».

## Распределение целей

Жадное распределение по предельной пользе. Ценность огня одного корабля по цели e:

`u = угроза(e) × ценность(e) × [P(уничтожить | D + свой вклад) − P(уничтожить | D)] / наблюдаемая целость`

- D — суммарный огонь тех, кто уже ведёт цель. Поэтому выгода от лишнего корабля на почти уничтоженной цели падает сама — без отдельного правила против избыточных сил.
- Свой вклад считается по реальному оружию корабля с учётом дистанции и манёвренности цели (`dpsAt`).
- Удержание цели: гистерезис `FC.hyst` на `FC.hold` с, затем цена смены `FC.swc`.

## Изменения этого этапа

1. **Ожившая строка распределения целей.** С `dadae4d` строка «незанятая серьёзная угроза ценится ×1,3» и «при устойчивой угрозе опасные цели дешевле» стояла после `//` и не выполнялась. Нашёл её новой проверкой `tools/lint-comment-code.cjs`. Включена; флаг `FC.fix` позволяет её выключить для сравнения.
2. **Удержание цели.** `hold` 20 → 45 с, `hyst` 1,25 → 1,6. Замер (6 боёв, одинаковые seed): смены целей −20 %, возвраты к прежней цели («пилообразные» смены) −44 %, меткость обеих сторон 35 % / 29 % → 39 % / 39 %. Числа — в `combat-tactics.md`.
3. Что уже было и проверено, но не перерабатывалось: роли (линия / поддержка / ПВО / перехват) по способностям корабля (`capOf`: огневая мощь, живучесть, ускорение — не по названию класса), передача флагмана, ПВО-сопровождение ценных кораблей.

## Не сделано (честно)

- **Групповой отход с прикрытием** не реализован. Отход по-прежнему решает каждый корабль сам, плюс флот перестаёт давать задачи ушедшим на базу. Что все бросают бой одновременно, отдельно не измерялось. Нужны счётчик одновременно отходящих и решение флота «прикрыть / отходить группой».
- **Новые построения** (клин, колонна) не добавлялись: есть линия с местами по бокам и поддержка за ней, строй держится штрафом в оценке плана.
- **Роли «разведчик» и «ремонтная поддержка»** не добавлены: в бою нет ни ремонта другого корабля, ни отдельного разведчика.
