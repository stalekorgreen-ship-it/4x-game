# Сходимость топлива, ИИ 100×100, ракеты, рендер — результаты

## Топливо: причина расхождения 572 / 442 с
- Тест F2 — настоящий бой 2×2: при другом шаге физики меняются моменты решений и попадания, бой идёт по-другому, и расход топлива тоже. Сам расчёт резерва от шага не зависит.
- Сценарий без боевого хаоса (drift, tools/fuel-conv.cjs): уход на базу на 1271,5 / 1270,5 / 1257,3 / 1256,3 с при шагах 0,5 / 0,25 / 0,125 / 0,0625 (разброс 1,2 %).
- По ходу проверки нашлись настоящие ошибки возвращения: ни один корабль не доходил до базы.
  1. Команда на базу шла в км/с без деления на тягу — корабль почти не двигался.
  2. Мёртвая зона скорости (0,1–0,2 км/с) была больше скорости перелёта (около 0,05 км/с) — корабль не мог даже набрать курс.
  3. Нос держался по направлению пути, а не по нужному импульсу — боковую скорость гасили только слабые маневровые.
  4. Торможения у базы не было — корабль пролетал мимо.
  5. Колебания на краю мёртвых зон давали лишние развороты, и расход маневровых зависел от шага.
- Допуски: время ухода ±2 %, время прибытия ±3 %, израсходованное топливо ±10 %. Полная таблица — fuel-convergence.txt.
- Где допуски не выполнены:
  - heavy: расход 214 / 216 / 222 / 227 т — 6 %, в допуске, но разброс есть.
  - far при шаге 0,125: пролёт базы (10,8 км на 0,20 км/с), при остальных шагах прибытие в пределах 2,6 км.
  - far: у базы остаётся всего 4–9 % топлива. Расчёт резерва не учитывает топливо маневровых на развороты.

## ИИ манёвра: из чего складывается решение (25×25, мс на одно решение)
| этап | мс |
|---|---|
| расчёт траекторий (predI, 50–80 вариантов × 60 шагов) | 7,1 |
| урон нанесённый/полученный | 4,3 (было 6,0 при 100×100) |
| контакт с кораблями врага | 0,3 (было 3,1–3,6) |
| угрозы, снаряды, таран, роль, топливо, наблюдение | менее 1 вместе |

Оптимизации дают бит-в-бит тот же результат боя (проверено md5 полного итога боя):
- кэш положений врага;
- один проход урона по трём вариантам манёвренности;
- сектора орудий один раз на решение;
- исправность маневровых призрака один раз на прогноз;
- без лишних массивов.
