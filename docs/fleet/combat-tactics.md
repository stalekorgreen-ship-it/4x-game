- Сводка: `runs/tactics-summary.json` (`tools/tactics-sum.cjs`).

## Что видно

- **Командование флота заметно повышает меткость:** 39 % против 27 % без него. Распределение по предельной пользе ставит корабли на цели, по которым их оружие работает.
- **Сторона с ролями в бою против стороны без них:** меткость 44 % против 30 %, потерь 8 против 11.
- **Удержание цели** уменьшило пилообразные смены почти вдвое (211 → 119–134).
- **Побед из 6 боёв мало для выводов.** У зеркальных составов есть заметный перекос в пользу стороны 0 (она стартует первой в списке). Для выводов о победах нужно 30+ seed и перестановка сторон.

## Не проведено

- Группы A и B (дуэли классов, разные флоты) и D (логистика) отдельным стендом не прогонялись. Частично их покрывают `missile-test`, `kit-fuel-test` и `fuel-conv`.
- Сценарии «потеря флагмана» и «потеря половины флота» отдельно не ставились. Счётчик передачи флагмана в данных есть (`fc.flagLost`).
- Метрики «время в эффективной позиции», «сохранение строя» и «время реакции» не собираются: нужно добавлять счётчики.
