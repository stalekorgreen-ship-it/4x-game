# Флоты / ракеты v4

- Синхронизация стороны (battle.command.sync): фазы сбор → сближение → бой; передовые флоты ждут, отставшие (после waitMax) не держат остальных; общая крейсерская = минимум.
- Физические ловушки (battle.decoy.phys): объект с временем жизни; ИК-головки (и комбинированные с севшей батареей) переключаются на ловушку, радарные — нет.
- Противоракеты (конструктор ракеты: «Назначение → противоракета»): перехват угрожающих ракет, не более amPer на одну.
- Выбор цели ракет (misPick): учёт уже летящих ракет, насыщение, бонус снабжению/танкерам, штраф за ПВО; без радиуса вокруг флота.
- Ракетные корабли держат дистанцию поддержки supR (по дальности ракет/сенсоров).
- F3: FPS и кадр считаются по последним 2 с.

Испытания (tools/missile-test.cjs): ИК против ловушек 8/8 уведены; радарные 8/8 попали; залп 28 ракет против 4 противоракет: 7 пусков, 4 перехвата.
engage-test (1 сид, 1800 с): разброс вступления флотов sync off 501/174 с, on 315/303 с — неоднозначно, нужна серия.
