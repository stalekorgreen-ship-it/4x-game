# Внутренние повреждения кораблей

Код: `src/05-battle.ts` (блок «ВНУТРЕННИЕ ПОВРЕЖДЕНИЯ»: `crewInit`, `crewKill`, `modEff`, `zoneAmmo`, `detonate`, `shipState`), параметры — `public/data/battle.json` разделы `crew`, `magazine`.
Отсек = зона корабля (нос, правый борт, корма, левый борт) с её модулями и бронёй — та же структура, что раньше; отдельной модели нет.

* Экипаж: группы «отсек × специальность». Расчёт каждого модуля (рельсотрон 6, картечница 2, ракеты 4, двигатель 3, маневровые 1, сенсоры 3, реактор 6), командование в носу, аварийные/жилые — по отсекам. По умолчанию численность = 1,25 × нужного (или `crew` проекта).
* Модуль работает с эффективностью 0,2 + 0,8·(доля расчёта); без расчёта — не работает; в отсеке без воздуха — 0,7; меньше 25% всего экипажа — всё хуже.
* Пробитие внутрь (броня остановила — ничего): гибель людей отсека по энергии удара и числу выбитых модулей (расчёт выбитого модуля — ×2,5), разгерметизация, задевание погреба.
* Погреб отсека: доля общего запаса по орудиям отсека; тротил. экв. — болванки 0,05, патроны 0,25, ракеты 1. Расход уменьшает опасность. Детонация: модули и люди отсека и соседних, броня изнутри, пожар, вакуум, энергия в секции корпуса (могут оторваться), цепные детонации, разрушение корабля при > 5 т экв. на 1000 т.
* Пожары: гибель людей, распространение к соседям, вторичная детонация у погреба; в вакууме гаснут.
* Состояния: боеспособен, повреждён, потерял часть функциональности, критически повреждён, обездвижен, потерял управление, не может вести огонь, выведен из строя, без экипажа (остов: дрейф по инерции, без огня и приказов), уничтожен.
* ИИ: роли и цели — по обслуживаемому оружию; корабли без оружия и остовы не получают задач; отход — по оставшимся возможностям; молчащие орудия врага постепенно не считаются угрозой.

Проверки: `tests.txt` (tools/dmg-sys-test.cjs, 19/19; детерминизм — tools/det-test.cjs), реальные бои — `battles.txt`, демонстрации A–D — `demo*.png` и `demo*.log` (tools/demo3d.cjs, сценарии A/B/C/D).
